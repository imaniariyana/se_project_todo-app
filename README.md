# Simple Todo App

A simple and interactive task management application that allows users to create, track, and organize their daily tasks. This project was built as part of the TripleTen Software Engineering program and focuses on applying Object-Oriented Programming (OOP), JavaScript modules, and form validation concepts.

## Functionality

The Simple Todo App allows users to:

View a list of preloaded tasks
Create new tasks through a popup form
Add optional due dates to tasks
Mark tasks as completed using checkboxes
Delete tasks when they are no longer needed
Receive real-time form validation feedback when creating tasks
Generate unique IDs for newly created tasks using the UUID package
